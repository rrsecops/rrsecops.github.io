# FortiAnalyzer Além dos Relatórios

**Do log à detecção. Da detecção à ação.**

Site GitHub Pages para explorar FortiAnalyzer sob a perspectiva de SecOps, Detection Engineering, Threat Hunting, Investigation, Correlation, Incident Response e Automation.

## Publicação

Copie o conteúdo deste pacote para a raiz de `renildo1994.github.io`.

No GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.

## Estrutura

- `index.md` — Home
- `start-here.md` — onboarding
- `secops/` — pilares de SecOps
- `_posts/` — artigos
- `_labs/` — Detection Labs
- `_detections/` — Detection Catalog
- `_research/` — Research & Field Notes
- `assets/css/` — identidade visual
- `_layouts/` — templates

A primeira arquitetura usa Jekyll/Minima e foi desenhada com referência ao FortiAnalyzer 7.4.1 Administration Guide. Valide sempre detalhes técnicos contra a documentação da versão efetivamente utilizada.
