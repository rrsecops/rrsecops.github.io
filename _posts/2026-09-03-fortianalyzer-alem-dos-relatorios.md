Existe uma associação comum quando falamos de FortiAnalyzer:

**logs e relatórios.**

Mas uma operação de segurança precisa de muito mais.

Precisa identificar comportamentos suspeitos, transformar eventos em sinais relevantes, investigar o que aconteceu, procurar evidências, correlacionar eventos e, quando necessário, transformar uma detecção em uma ação.

É nesse espaço que nasce o **FortiAnalyzer Além dos Relatórios**.

## A pergunta central

> **Como podemos utilizar o FortiAnalyzer para apoiar uma operação de segurança?**

Esta não é uma newsletter de pré-venda e não pretende ser um catálogo de funcionalidades.

A proposta é partir de problemas de SecOps e explorar, de forma prática, como o FortiAnalyzer pode apoiar atividades de:

**Detecção → Investigação → Threat Hunting → Correlação → Resposta → Automação**

## O princípio

Não vamos começar perguntando:

> “Qual funcionalidade do FortiAnalyzer posso demonstrar?”

Vamos começar perguntando:

> **“Qual problema de segurança queremos resolver?”**

A partir daí:

**Problema → Hipótese → Dados → Detecção → Validação → Investigação → Ação**

## O que vem pela frente

A primeira temporada explorará Log ≠ Detection, Detection Engineering, Event Handlers, falsos positivos e tuning, Correlation, Threat Hunting, Investigation, MITRE ATT&CK e Automation.

Sempre com uma preocupação:

> **O que isso significa para o analista e para a operação?**

## Uma pergunta para acompanhar o projeto

Se você utiliza FortiAnalyzer principalmente para responder:

> “O que aconteceu?”

talvez exista uma pergunta ainda mais interessante:

> **“O que podemos detectar, investigar e aprender com os dados que já temos?”**

Bem-vindo ao **FortiAnalyzer Além dos Relatórios**.
